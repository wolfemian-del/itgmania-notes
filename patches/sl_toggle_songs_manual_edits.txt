Do this AFTER installing the patched ITGmania build. Close the game first.
Edit two files inside the installed folder, e.g.
  C:\Games\ITGmania\Themes\Simply Love\metrics.ini
  C:\Games\ITGmania\Themes\Simply Love\Languages\en.ini
Use Notepad (or any plain-text editor). Make a backup copy of each first.
Easier: sl_toggle_songs.patch contains the same edits in diff form.

FILE 1: metrics.ini
 (a) Find the line starting   local lines = "SystemOptions,MapControllers,
     and change the end of that line
        ...,StepManiaCredits,ClearCredits,Reload"
     to
        ...,StepManiaCredits,ClearCredits,ToggleSongs,Reload"
 (b) Find the line   LineGrooveStatsOptions=...   and add right below it:
        LineToggleSongs="gamecommand;screen,ScreenOptionsToggleSongs;name,Toggle Songs"
 (c) Find   [ScreenSystemOptions]   and add ABOVE it (blank line between):
        [ScreenOptionsToggleSongs]
        Fallback="ScreenOptionsServiceChild"
        PrevScreen="ScreenOptionsService"
        NextScreen="ScreenOptionsService"

        [ScreenOptionsToggleSongsSubPage]
        Fallback="ScreenOptionsServiceChild"
        PrevScreen="ScreenOptionsToggleSongs"
        NextScreen="ScreenOptionsToggleSongs"

FILE 2: Languages\en.ini
 (a) In section [OptionTitles], below the line  Reload Songs=...  add:
        Toggle Songs=🤍  Toggle Songs
     (the heart and the two spaces are what the neighbouring lines use, e.g.
     "Reload Songs=🤍  Reload Songs/Courses"; copy the prefix from that line)
 (b) In section [OptionExplanations], below  Key Joy Mappings=...  add:
        Toggle Songs=Turn song packs and individual songs on or off.
 (c) Below the line  HeaderText=System Options  (section [ScreenSystemOptions])
     add:
        [ScreenOptionsToggleSongs]
        HeaderText=Toggle Songs

        [ScreenOptionsToggleSongsSubPage]
        HeaderText=Toggle Songs
Save both files, start the game, open the operator (service) menu: a
"Toggle Songs" entry should appear above "Reload Songs".
If the game shows a metrics/script error on start, undo the edits using the
backups and send me the message. (Not tested in game.)
