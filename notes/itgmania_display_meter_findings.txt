    "Chart" row (Scripts/SL-PlayerOptions.lua, non-Edit branch kept "%i"). With Both mode the text is
    "13 (12)", and string.format("%i", "13 (12)") raises an error, which would have broken that screen.
    Both branches now use "%s" [TESTED-MOCK: format call with a Both string].

  - Pack.ini key matching now ignores case and spaces in the KEY. IniFile.ReadFile does not trim keys, so
    "DifficultyMode = modeled" produced the key "DifficultyMode " and was silently ignored
    [TESTED-MOCK: failed before the fix, passes after; CODE: 01 IniFile.lua StrToKeyVal pattern "(.+)=(.*)"].
  - Rating does not depend on which player is joined: Steps::GetNpsPerMeasure / GetNotesPerMeasure /
    GetPeakNps fall back to the PLAYER_1 data when fewer per-player copies exist [CODE: Steps.cpp 932-1000].
    DifficultyModel.Rating defaults to PLAYER_1 anyway.

3. LUA CAPABILITIES THAT MATTER [CODE, engine v1.3.0]
  - Steps:GetFilename() is bound and returns a path ending ".../<Pack>/<Song>/<file>.sm" (SL-ChartParser.lua
    opens it directly) [CODE]. Whether it starts "Songs/", "/Songs/" or something else is not checked: the
    patch no longer depends on that (see check 3, section 8).
  - Lua can read files: RageFileUtil.CreateRageFile() with Open/Read/GetLine/AtEOF (RageFile.cpp
    ~395-470); Simply Love already reads song files with it (Scripts/SL-ChartParser.lua:15).
  - Lua IniFile.ReadFile(path) exists in _fallback Scripts/01 IniFile.lua. It returns a table keyed by
    section, then key; values are converted to number/boolean when they look like one; blank table (and a
    Warn) when the file cannot be opened. Differences from the engine reader (Group.cpp uses the C++
    IniFile): the Lua version skips only lines starting with "#" (the C++ reader also skips ";", "//",
    "--" per engine notes 7l), does not trim keys or values, and splits at the last "=" [CODE; Group.cpp 79-106].
    The patch calls FILEMAN:DoesFileExist first (no Warn spam for packs without Pack.ini), matches the key
    ignoring case and spaces, and trims and lower-cases the value itself.
  - Group has NO Lua accessor for the pack folder or for arbitrary keys (Group.cpp ADD_METHOD list ends at
    GetYearReleased; C++ Group::GetPath exists, Group.h:40, but is not bound). The engine builds the
    Pack.ini path as <songs dir><pack dir>/Pack.ini [CODE: Group.cpp 47-54].
  - Group.cpp reads Pack.ini only when [Group] Version is non-empty, and ignores keys it does not know
    [CODE: fixed key list]. So an extra key is harmless to the engine. The Lua reader does not check Version,
    so a Pack.ini without Version still drives DifficultyMode while the engine ignores the rest of that file
    [INFERRED]. Put Version=1 in the file to keep both readers consistent.
  - Engine route for a per-pack key (not needed now): add to the vPackfields list in Group::Group, a member,
    a Lua binding and a docs line. Same shape as the SeriesBanner commit (36dc1925bd).

4. WHAT THE PATCH DOES (patches/sl_display_meter.patch; Simply Love dd06138) [CODE, patch text]
  Pref (theme pref, Simply Love Options screen, default Official):
    DifficultyDisplay = Official | Modeled | Both | PerPack
    Files: Scripts/99 SL-ThemePrefs.lua (definition), metrics.ini (LineNames + LineDifficultyDisplay),
    Languages/en.ini (option title, explanation, four choice strings under [ThemePrefs]).
    Other language files are untouched; THEME:GetString should fall back to en.ini for missing keys
    [INFERRED, not checked: see check 9].
  New file Scripts/SL-DisplayMeter.lua (global table DisplayMeter):
    DisplayMeter.Text(steps, compact)  display string. Official meter when: mode is official; DifficultyModel
        is missing; Rating returns nil (not dance-single, no data); steps is an Edit; course mode; steps nil
        (returns ""). Modeled: the rating. Both: "13 (12)", or just "13" when the numbers are equal or when
        compact=true.
    DisplayMeter.Number(steps)  modeled number when mode is modeled/both and a rating exists, else official.
    DisplayMeter.Matches(steps, n)  filter test: Number == n; in Both mode the official meter also matches.
    DisplayMeter.Reset()  clears the caches.
    PerPack: reads [Group] DifficultyMode=official|modeled|both (value case-insensitive and trimmed; key
        case-insensitive, spaces ignored) from <pack folder>/Pack.ini, the folder being steps:GetFilename()
        minus its last two path components. Cached per folder for the session. Missing file, missing key or
        bad value = official. Editing a Pack.ini needs a game restart.
    Rating cache key: filename|StepsType|Difficulty|Description. A chart edited in place and loaded again with
        Reload Songs keeps its old cached rating until the game restarts (call DisplayMeter.Reset() to clear).
  Edited display sites (compact = small cells show only the modeled number; wide = may show "13 (12)"):
    StepsDisplayList/Grid.lua (compact), TabbedStepchartList/default.lua (compact), PaneDisplay.lua (wide;
    course mode keeps Trail:GetMeter()), SongSearch/default.lua (wide), gameplay DifficultyMeter.lua
    (compact; also adds a nil-steps guard), evaluation Upper/Difficulty.lua (compact, non-course branch only),
    evaluation Storage.lua (Number; feeds the summary screen), SL-PlayerOptions.lua Chart row (wide; both
    "%i" formats changed to "%s").
  Filter sites routed through DisplayMeter.Matches: SortMenu/default.lua, SongSearch/SongSearchSettings.lua.
  DEPENDENCY: claude/DifficultyModel.lua must already be in the theme's Scripts folder (the patch does not
    include it). Without it every site shows the official meter.
  Not changed: see sections 1-2 (CustomScores, nice.lua, Casual, StepsToDisplay, engine sorts, EditMenu).
  Does NOT touch the DifficultyModelCheck overlay: remove or disable it separately (section 7).

6. RISKS
  - Mixed scales on one screen: modeled DDR-X-scale numbers next to community-scale official numbers.
    Motivates the per-pack setting; default is Official.
  - Beginner/Easy slot-convention charts are the known weak spot (writeup 5.6). Edit charts are not rated.
  - Rating 18-19 least reliable (thin data); 20 is never produced.
  - Wheel Meter sort follows the official meter while the display follows the pref (section 2).
  - Both mode in the pane and in the Chart row on ScreenPlayerOptions makes longer strings
    [UNVERIFIED how they fit; the pane text has no maxwidth on widescreen].
  - Evaluation summary and the "Storage" copy show the modeled number whenever the pref is not Official,
    including for charts played under another setting earlier in the session [INFERRED].
  - Cache staleness after editing a chart (section 4).
