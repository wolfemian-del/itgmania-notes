# Notes for AI agents

Read INDEX.md first. Use its topic table and prefix glossary to open one file in notes/; do not read the whole repo.

- Every technical claim is tagged [CODE], [INFERRED], [UNVERIFIED] or [TESTED]/[OBSERVED]. Only the last is proven in game.
- Status labels (INDEX.md, FILE STATUS LABELS) are not proof: PATCH-APPLY-CHECKED and ARCHIVE must not be treated as production-proven unless the note says [TESTED]/[OBSERVED].
- Edit files in place; when a note changes, bump its REVISION line and update its INDEX.md row in the same commit.
- New files go in notes/, patches/ or tools/ (never the repo root except INDEX.md, README.md, NOTICE, AGENTS.md). Use underscores in filenames.
